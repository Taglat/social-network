📦 Архитектура проекта и инструкция по запуску

Проект полностью изолирован в Docker-контейнерах и собирается одной командой.

1. Быстрый запуск в Docker Compose

Из корня репозитория запустите команду для сборки двух контейнеров:

# Сборка и запуск бэкенда (Go) и фронтенда (Next.js)
docker compose up --build

🌐 Фронтенд: http://localhost:3000

🔌 API Бэкенда: http://localhost:8080

2. Тестовые учётные записи (Seed)

Email Пароль Тип профиля
bob@demo.local password123 Публичный
carol@demo.local password123 Приватный (требует подтверждения подписки)
dave@demo.local password123 Публичный

3. Десктоп-мессенджер (Electron / AppImage)

# Запуск десктопного мессенджера
cd desktop
npm install
npm start
# Сборка установщиков:
npm run dist:linux # AppImage для Linux
npm run dist:win # .exe инсталлятор для Windows
